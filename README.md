# 🇰🇷 VocaKeeper

A simple Korean vocabulary learning and management application built with **Python, Flask, and SQLite**.

## ✨ Features

* ➕ Add new Korean words with Persian meanings
* 📖 View saved vocabulary
* 🔍 Search for words
* 🗑️ Delete vocabulary
* 💾 Store vocabulary using SQLite
* 🌐 Simple web interface

## 🛠️ Technologies

* **Python**
* **Flask**
* **SQLite**
* **HTML**
* **CSS**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/mahak-khalili05/VocaKeeper.git
cd VocaKeeper
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 4. Install Flask

```bash
pip install flask
```

### 5. Run the application

```bash
python app.py
```

Then open the local address shown in the terminal.
