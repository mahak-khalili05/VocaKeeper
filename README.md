# VocaKeeper 🇰🇷

VocaKeeper is a simple Korean vocabulary management application built with Python and SQLite.

## Features

- Add Korean vocabulary
- Save Persian meanings
- View saved words
- Search vocabulary
- Delete words
- Store data using SQLite

## Technologies

- Python
- SQLite
- Flask
- HTML/CSS
- Git & GitHub

## Purpose

VocaKeeper was created as a practical project for learning Python, databases, and basic web application development while building a useful Korean vocabulary tool.
